Under the hood

What every site ships with.

Built once, applied to every member. The same SEO, automation, and design tokens land on each repo.

Weekly Google Scholar sync

A GitHub Actions workflow runs every Monday morning, fetches the latest publication list and citation metrics via SerpApi, and re-renders the static HTML before commit.

Schema.org + JSON-LD

Person markup with sameAs links to Scholar, ORCID, LinkedIn, and ResearchGate so Google's Knowledge Graph can build a researcher entity that surfaces in name searches.

Server-rendered content

Publications and metrics are baked into the HTML at workflow time, not fetched after page load. Googlebot's first crawl pass sees everything immediately.

Open Graph + Twitter cards

Every page gets rich link previews on LinkedIn, Twitter, Slack, Discord, and any other platform that reads OG tags.

Sitemap + robots

Each site ships an XML sitemap so search engines find every page on first visit, plus a robots file pointing back to the sitemap.

Dark + light, mobile-first

Both color schemes shipping by default with a system-aware toggle. Responsive breakpoints down to ~360px.
