What every site ships with.

Built once, applied to all four repos. The same automation, structured data, and design tokens land everywhere.

Weekly Scholar sync

A GitHub Action runs every Monday, pulls fresh publications and citation counts, and rebuilds the static pages before committing.

Schema.org entities

Organization and Person JSON-LD with sameAs links to Scholar and ORCID, so search engines resolve each member as an entity.

Build-time rendering

Numbers land in the HTML during the workflow, not after page load. Crawlers see final content on the first pass.

Rich link previews

Open Graph and Twitter card tags on every page, so shared links unfurl cleanly on LinkedIn, Slack, and X.

Sitemaps and robots

Every repo ships an XML sitemap and a robots file, so new pages are discovered on the first crawl.

Dark and light themes

System-aware color schemes, responsive down to small phones, no frameworks, one hand-written HTML file per page.
